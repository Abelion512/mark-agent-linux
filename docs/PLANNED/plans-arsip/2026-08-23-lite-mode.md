# Lite Mode (RAM 4GB Optimization) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Auto-detect low RAM (≤4GB) di runtime, silent-disable fitur berat (3D graph, WASM embeddings, lazy browser agent) dengan fallback ringan yang mempertahankan fungsi 100%, plus badge kecil pojok kiri atas sebagai info user.

**Architecture:** Main process detect RAM via `os.totalmem()` saat startup → kirim flag ke renderer via IPC → `LiteModeContext` expose flag ke seluruh React tree → setiap fitur berat baca flag & pilih jalur ringan. Tidak ada perubahan arsitektur — cuma conditional branches.

**Tech Stack:** Electron 39 (`os` module, IPC), React 19 Context, existing deps only (zero new packages).

**Spec:** Interview session 2026-08-23 dengan owner:
- Target: pengguna publik Linux dengan RAM ≤4GB
- Strategi: silent auto-disable + badge informatif (bukan prompt/modal)
- Fungsi tidak boleh hilang — hanya jalur eksekusi yang lebih ringan
- Badge posisi: pojok kiri atas (kanan dipakai music player)
- Target dampak: ≥10% RAM turun, responsivitas tetap
- Berlaku untuk dev (`npm run dev`) dan build (`.AppImage`)
- Override manual: env `LITE_MODE=1` force on, `LITE_MODE=0` force off

## Global Constraints

- Zero new npm dependencies — pakai `os.totalmem()` stdlib, existing libs
- Semua fitur harus tetap berfungsi di Lite Mode (fallback path wajib ada)
- Badge non-blocking: bukan modal, auto-dismiss atau klik-close saja
- Threshold: `totalRAM <= 4GB` (mesin "4GB" real-usable ~3.7 setelah iGPU) → lite ON
- Env override: `process.env.LITE_MODE === '1'` → force ON; `'0'` → force OFF
- Jangan sentuh file Windows-specific (pc-agent-scripts/, telegram/) — Linux-only fork tapi jangan pecahkan upstream diff

- Modify: `src/main/index.js` (tambah IPC handler + kirim flag saat web contents ready)

**Interfaces:**
- Produces: `detectLiteMode(): { isLite: boolean, totalRAMGB: number }` — exported from systemInfo.js
- Produces: IPC `system:get-lite-mode` (invoke/handle), event `system:lite-mode-changed` (main→renderer)
- Produces: `window.electronAPI.getLiteMode()`, `window.electronAPI.onLiteModeChanged(cb)`

- [ ] **Step 1: Buat systemInfo.js**

```javascript
import os from 'os'

const GB = 1024 ** 3

export function detectLiteMode() {
  const envOverride = process.env.LITE_MODE
  const totalRAMGB = os.totalmem() / GB
  if (envOverride === '1') return { isLite: true, totalRAMGB: +totalRAMGB.toFixed(1) }
  if (envOverride === '0') return { isLite: false, totalRAMGB: +totalRAMGB.toFixed(1) }
  // Mesin "4GB" real-usable ~3.6-3.9 (iGPU reserve). Bias ke lite di <=4.2.
  const isLite = totalRAMGB <= 4.2
  return { isLite, totalRAMGB: +totalRAMGB.toFixed(1) }
}
```

- [ ] **Step 2: Register IPC di main/index.js**

Cari blok `ipcMain.handle()` lain. Tambah:

```javascript

```

- [ ] **Step 3: Push flag saat renderer ready**

Di `mainWindow.webContents.on('did-finish-load')` (atau setelah loadURL sukses):


### Task 2: LiteModeContext + Hook

**Files:**
- Create: `src/renderer/src/contexts/LiteModeContext.jsx`
- Modify: `src/renderer/src/main.jsx` (wrap App)

**Interfaces:**
- Consumes: `window.electronAPI.getLiteMode()`, `window.electronAPI.onLiteModeChanged(cb)` dari Task 1
- Produces: `useLiteMode(): { isLite, totalRAMGB, loading }`

- [ ] **Step 1: Buat context**

```jsx
import { createContext, useContext, useEffect, useState } from 'react'

const LiteModeContext = createContext({ isLite: false, totalRAMGB: null, loading: true })

export function LiteModeProvider({ children }) {
  const [state, setState] = useState({ isLite: false, totalRAMGB: null, loading: true })

  useEffect(() => {
    let mounted = true
    window.electronAPI.getLiteMode?.()
      .then((info) => mounted && setState({ ...info, loading: false }))
      .catch(() => mounted && setState({ isLite: false, totalRAMGB: null, loading: false }))
    const cleanup = window.electronAPI.onLiteModeChanged?.((info) =>
      mounted && setState({ ...info, loading: false })
    )
    return () => { mounted = false; cleanup?.() }
  }, [])

  return <LiteModeContext.Provider value={state}>{children}</LiteModeContext.Provider>
}

export function useLiteMode() {
  return useContext(LiteModeContext)
}
```

- [ ] **Step 2: Wrap App**

Di `src/renderer/src/main.jsx`:


- [ ] **Step 2: Lite branch**

```javascript
let warned = false
const hashEmbedder = {
  async encode(text) {
    if (!warned) { console.info('[vectorMemory] Lite: hash embeddings (no WASM)'); warned = true }
    const vec = new Float32Array(384)
    for (const tok of text.toLowerCase().split(/\s+/)) {
      const h = fnv1a(tok) % 384
      vec[h] += 1
    }
    const norm = Math.sqrt([...vec].reduce((s, v) => s + v * v, 0)) || 1
    return Array.from(vec.map((v) => v / norm))
  }
}
function fnv1a(str) {
  let h = 2166136261
  for (let i = 0; i < str.length; i++) { h ^= str.charCodeAt(i); h = Math.imul(h, 16777619) }
  return h >>> 0
}
```

Ganti guard pipeline init: `if (isLite) return hashEmbedder`. Sesuaikan method name (`encode`/`embed`) dengan API file.
